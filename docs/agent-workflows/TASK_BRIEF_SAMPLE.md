# Task brief example — extend an educational exhibit

## Goal

Extend an existing exhibit with an additional parameter comparison that helps a student explain the paper's mechanism.

## Constraints

Preserve the frontend-only React/Vite architecture and local runtime. State the mathematical assumption and cite the relevant PDF page. Keep illustrative outputs labeled as such. Do not add paid services, live feeds, or an API solely to compute a chart.

## Required output

A working accessible control and visualization, a clear explanatory paragraph, meaningful numerical tests, a passing `npm run build`, and a narrow-screen browser smoke check. Update durable documentation only where the behavior or commands changed.

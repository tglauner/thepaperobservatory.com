Stochastic flow diagrams: shocks, lags and feedback

This educational companion examines Stochastic flow diagrams by Neil J. Calkin and Marcos López de Prado, published in Algorithmic Finance in 2014. A stochastic flow diagram makes the architecture of a specified time-series model visible: variables become nodes, signed regression coefficients become directed arrows, and lag nodes represent memory.

How a shock moves through the model

For a first-order vector autoregression, the next state equals a coefficient matrix times the current state, plus a new innovation. In these diagrams, a matrix row is the target and a column is the source. All target values must be computed from the old state before moving to the next model period. Updating one node in place and immediately using it elsewhere would change the equations.

Arrow coefficients describe contributions in the specified model. An arrow is not a measured flow of money and does not establish causality. In models with several lags, memory nodes retain earlier states and shift them forward together. The visual animation separates reading memory, adding contributions and shifting the state; those explanatory phases are not separate economic time steps.

Stability and interpretation

The experiments compare how an initial impulse decays, persists or grows. For a first-order linear discrete-time system, stability depends on the moduli of the coefficient matrix's eigenvalues; multiple-lag systems use the corresponding companion matrix. Complex eigenvalues can produce oscillation. Behavior on the unit circle needs additional care, and an invertible matrix need not be diagonalizable.

The paper's worked examples are stylized systems, not fitted market data, a causal network estimate or a crash forecast. The companion labels synthetic experiments and teaching extensions. In the uncertainty experiments, Gaussian bands with fixed coefficients are outcome bands rather than confidence intervals for estimated parameters. Read assumptions alongside each result.

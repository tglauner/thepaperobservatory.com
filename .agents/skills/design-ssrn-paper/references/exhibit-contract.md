# The Paper Observatory exhibit contract

A companion belongs at `papers/<slug>/` with its own source, analysis, application, tests and paper guide. The public URL prefix, Vite base, catalog entry, launcher registration and assembled build directory must agree. Existing examples are `risk-on-off` and `stochastic-flow-diagrams`.

The shared entrance and shell give readers a stable route to the library, related exhibits, courses and channels. Within each paper, provide a readable overview, interactive mechanism, evidence/limitations and a way to assess understanding. Use the existing learning-depth control and navigation conventions; add sections only when the paper needs them. Keep the source attribution visible and preserve deep links.

Before visual design, make a compact decision record in the paper analysis:

| Decision | Evidence to record |
| --- | --- |
| Why this paper | The mechanism improved by direct manipulation; subject fit or exception rationale |
| Reader task | What the reader will change, observe and explain afterward |
| Source contract | SSRN ID/version, original hash, page map, rights status, canonical reading link |
| Model contract | Equations, orientation, units, initial state, parameter ranges, exact versus synthetic examples |
| Initial design | Actual model/reasoning, chosen central visual, Foundation/Advanced disclosure, mobile alternative |
| Accuracy checks | An analytic identity, a source reconstruction where possible, a boundary/limiting case |
| Growth path | A genuinely related course, source-faithful short-form hook and canonical CTA |

Teaching rules that matter here:

- A chart needs units, state and a textual value or interpretation. Do not make color the only carrier of meaning.
- Financial simulation is educational; do not present synthetic outcomes as current market forecasts, fitted evidence or an investment recommendation.
- Directed predictive graphs do not automatically establish causal intervention effects. Uncorrelated quantities need not be independent. Parameter uncertainty and outcome variation are distinct.
- Period changes, cumulative sums and compounded returns are different quantities. State which one is displayed.
- Do not infer stability from a real-part test in a discrete-time model. Use the correct spectrum and companion system for the stated dynamics.
- Reconstruct source examples honestly; explicitly qualify an error or overbroad source statement rather than reproducing it uncritically.

For acceptance, the main control must change the stated mechanism; reset must restore a described state; mobile and keyboard users must reach the same learning result; evidence references must point to the correct source/version. Course, ad and social placements support the learning path without masquerading as research content.
